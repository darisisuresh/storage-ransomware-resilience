# Changelog

All notable changes to the public research companion are documented here.

## [1.0.0] — 2026-10-05

- Added a safe deterministic numeric-telemetry emulator and reference detector.
- Published reproducible aggregate evidence for 40 seeds, six workload profiles, six benign confounders, and 28,800 adversarial trials.
- Added per-trial CSV data, a machine-readable JSON summary, SHA-256 checksums, architecture and results figures, and explicit claim boundaries.
- Added CI, history-aware manuscript/privacy scanning, secret-pattern checks, Dependabot configuration, a security policy, and private vulnerability reporting.
- Expanded the evaluation protocol and prepared a private IEEE manuscript revision; no manuscript or extracted prose is included in this repository.
